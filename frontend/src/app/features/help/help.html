Aide

Comment candidater à un projet ?

Ouvrez un projet, puis cliquez sur “Postuler”. Vous pouvez suivre l’état dans “Mes candidatures”.

Pourquoi je ne peux pas créer un projet ?

Tous les utilisateurs connectés peuvent proposer un projet. Ensuite, vous pouvez gérer les candidatures et constituer votre équipe.

Comment améliorer mes recommandations ?

Ajoutez vos compétences dans “Mon profil”. Les projets recommandés se basent sur les technologies en commun.
