# Frontend — ConnectED (Angular)

Le frontend est une application Angular. Pour un lancement complet (frontend + backend + Neo4j), utiliser Docker Compose depuis la racine du projet.

## Lancement recommandé (depuis la racine)
```bash
docker-compose up --build
```

## Développement local (sans Docker)
Prérequis : Node.js + npm.

```bash
npm install
npm run start
```

L’application est accessible sur http://localhost:4200.

## Build
```bash
npm run build
```
